Proje #1

Siber Güvenlik Teorisi

TCP Port Tarama (SYN Scan): Her port’a TCP SYN paketi gönderilir. SYN-ACK cevabı alınırsa port açıktır. RST veya cevapsızlık kapalı anlamına gelir. Bu, Nmap’in kullandığı temel keif tekniğidir.

Banner Grabbing: Açık porta bağlanarak servis versiyon bilgisi (HTTP Server, SSH banner vb.) okunur. Zafiyet tespitinde kullanılır.

TTL tabanlı OS Tespiti: IP paketlerindeki TTL değeri işletim sistemine göre değişir: Linux~64, Windows~128, Cisco~255.

Nasıl Kodladım?

Python socket modülü ile her porta TCP bağlantı deneniyor. concurrent.futures.ThreadPoolExecutor ile çok iş parçacıklı paralel tarama sağlandı. socket.recv(1024) ile banner yakalanarak servis tespiti yapılıyor.

Python socket ThreadPoolExecutor TTL Analizi Banner Grabbing

Proje #2

Siber Güvenlik Teorisi

Paket Yakalama (Packet Sniffing): Ağ ara yüzüne gelen tüm IP paketlerini yakalamaktır. Promiscuous mode ile kendi paketleri dışındaki paketler de okunabilir. Wireshark aynı prensibi kullanır.

OSI Modeli Katman Analizi: IP header (Katman 3) struct.unpack ile ayrıştırılır. TCP/UDP/ICMP header (Katman 4) payload’dan parse edilir. Her alanda version, TTL, flags, checksum bilgileri elde edilir.

Hex/ASCII Dökümü: Payload byte dizisi 16’lık gruplara bölünerek hem hex hem ASCII gösterimi yapılır. Yazdırılamaz karakterler ‘.’ ile maskelenir.

Nasıl Kodladım?

Python struct modülü ile binary veri ayrıştırması yapıldı. struct.unpack('!BBHHHBBH4s4s', raw[:20]) ile IP header büb alanlarına ayrıştırıldı. Vercel kapatıklarından dolayı örnek paket üretici ile demo sağlanmıştır.

struct.unpack Raw Socket OSI Layer 3/4 Hex/ASCII

Proje #3

Siber Güvenlik Teorisi

DNS Tunneling (Veri Sızdırma): Saldırganlar DNS sorgularının içine şifreli/base64 veri gömerek firewall’ları atlatarak veri sızdırabilir. Ağda çok sayıda DNS sorgusu veya anormal uzun subdomain isimler bunu ele verir.

Shannon Entropi: Bilgi teorisinde rastgelelik ölçüsüdür. Metin ne kadar rastgele ve şifreli görünürse entropi değeri (0-5) o kadar yüksektir. Normal subdomain’ların entropisi düşükken, base64 payload’lar çok yüksek entropi gösterir.

Nasıl Kodladım?

Python socket.gethostbyname() ile A kayıtları, dns.resolver ile MX/NS/TXT kayıtları sorgulandı. Shannon entropi formülü: H = -Σ(p × log₂p) ile math.log2() kullanılarak subdomain analizi yapılıyor ve risk skoru hesaplanıyor.

socket.getaddrinfo dns.resolver Shannon Entropi math.log2

Proje #4

Siber Güvenlik Teorisi

Kriptografik Hash Fonksiyonları: Bir girdiyi sabit uzunluklu, geri döndürülemez özete dönüştürür. Aynı girdiden her zaman aynı özet üretilir. MD5 (128-bit) kırılmıştır, SHA-256 günümüzde standarttır.

Salting (Tuzlama): Parola hashlemeden önce rastgele veri eklenerek Rainbow Table saldırıları engellenir. Aynı parola farklı tuzlarla farklı hash üretir.

NTLM Hash: Windows sistemlerin SAM veritabanında kullandığı MD4 tabanlı parola hash formatıdır. Pass-the-Hash saldırılarında hedef alınır.

Nasıl Kodladım?

Python hashlib modülü ile MD5, SHA-1/224/256/384/512 üretimi yapıldı. NTLM için hashlib.new('md4', text.encode('utf-16le')) kullanıldı. Hash identifier algoritması uzunluk + regex + önek desen eşleştirmesi ile çalışır.

hashlib SHA-256 / SHA-512 NTLM / MD4 Salting
